渡航前の流れ

渡航前に意外と費用がかさむので要注意。 出発までにやることは、
  1. ビザ（日本で取得推奨）
  2. Expatrio（閉鎖口座）を開いて送金 €992 × 留学期間（月）
  3. 健康保険（TKなど 予約）→ M10 を UDE に提出
  4. 寮に応募 → Reservation Fee €850 送金 → 契約書を郵送
  5. 大学：Semester Contribution €349.80 振込 + UDE アカウント設定 + Placement Test

1. ビザ

日本で取得することを推奨。（内容は後日追加）

2. Expatrio（閉鎖口座 / Sperrkonto）

ビザと現地生活の資金証明のために、閉鎖口座の開設が必須。Expatrio が定番で、契約は 2 パターン。

  • A. Blocked Account Only — 閉鎖口座 + 現地口座。健康保険は別で契約。
  • B. Value Package — 閉鎖口座 + 現地口座 + 健康保険（TK）込み。
    健康保険が €141.16 / 月 になる（高め）。

共通の流れ：契約 → 日本から全額を Wise で送金 → 到着後 Expatrio アプリでビデオ通話 ID 認証 → 毎月 €992 が現地口座に振り込まれる。

公式：Expatrio

3. 健康保険（TKだと、€141.16 / 月 になる（高め）。）

ドイツ滞在は公的健康保険加入が必須。Expatrio Value Package 経由で TK になる。他の海外留学保険に入る必要はない。

M10 confirmation（加入証明）を 2 月中旬までに UDE へ提出。TK / Expatrio が発行する PDF を IWO に転送するだけ。

到着後は Expatrio アプリでアクティベーション書類を提出 → 承認されると tk-welcome@tk.de から Membership Certificateが郵送される。 → ここに書いてあるQRからID／PASSWORDを入力すると、健康保険カードが郵送される。

4. 寮（Studierendenwerk Essen-Duisburg）

流れ

  1. 応募 → Offer 到着（Ident-Nr. と Onlineportal 用 web password が届く）
  2. Reservation Fee €850 を送金
    この €850 は敷金。返ってくる。
  3. パスポート画像を Onlineportal にアップロード
  4. Mietvertrag 4 枚が郵送で届く → 灰色欄 2 箇所に自署 → SEPA-Lastschriftmandat と一緒に 原本を国際郵送（EMS）。
  5. 到着 1 週間前に Hausverwalter へアポ（ID と部屋番号を伝える）
  6. 到着日に寮の事務所で鍵を受け取る

費用

項目金額
家賃（Inklusivmiete = 光熱・水道・寮 WiFi 込み）€418 / 月
Kaution（Reservation Fee が振替）€850

部屋の設備：家具付き（ベッド + マットレス・机・椅子・キャスター収納・クローゼット・棚）。

公式：Studierendenwerk Wohnen / Online-Bewerbung

5. 大学関連（UDE）

Semester Contribution：€349,80 / 学期。

UDE アカウント： UDE アプリでログインしておくと、Semester ticketがもらえる。

到着直後（〜2週間）

到着から2週間以内に片付ける役所系＋生活基盤。ここが遅れると在留許可申請が止まる。

1. ビザ／在留許可（Aufenthaltstitel）

Duisburg はオンライン申請に対応。到着後すぐに Ausländerbehörde Duisburg のポータルから申請する。Case No. が返信で届く。

ビザ申請をしたとしても最初に受け取れるのは 在留許可Aufenthaltstitel です。ノービザで入国した場合、90日を過ぎると、この許可だけではドイツ国外に移動できないので、

公式：Ausländerbehörde Duisburg ／ 問合せ abh@stadt-duisburg.de

2. 住民登録Anmeldung

Bürgeramt で予約 → 窓口で数分。家主証明Wohnungsgeberbescheinigung（寮が発行済み）とパスポート・契約証明Mietvertrag を持参。
発行される Anmeldebescheinigung が在留許可申請の必須添付。

3. SIM（ALDI TALK）

到着日に ALDI 店頭で SIM 購入 → パスポート ID → 数時間で開通。Prepaid・契約なし・EU 内ローミング可。翌月以降はオンラインで更新可能。

プランはTarif S がいい。ドイツ国内25GB/月・ドイツ外EU圏内15GB/月で€9.99/月

公式：ALDI TALK

4. TK 加入本手続き

到着後は Expatrio アプリでアクティベーション書類を提出 → 承認されるとMembership Certificateが郵送される。 → ここに書いてあるQRコードからID／PASSWORDを入力すると、健康保険カードが郵送される。それまでは、加入証明書で病院にかかれる。

5. 学生証（Studierendenausweis）

Semester Contribution 入金確認後、UDE から郵送。

6. 履修登録・ドイツ語 Placement Test

LSF で本登録 → 個別 Moodle は科目ごとに教員へ enrolment key をメールで依頼。IN-EAST 生の窓口は iwo@uni-due.de。

ドイツ語は3月中旬〜下旬にオンライン Placement Test → クラス判定。クラス変更依頼は sprachkurse@uni-due.de。

7. Learning Agreement

UDE への提出は履修が確定してから（iwo@uni-due.de 宛メール添付）。

8. Exam Registration

4 月下旬に IWO から一斉案内 → 5/15 頃締切。遅延登録不可。

9. UniSports

学期はじめの登録開始。料金を払わずに潜り込めることもある。

公式：Hochschulsport UDE

10. GEZ（放送受信料）免除

Anmeldung 後に自動で請求書が来ることがある。学生免除の申請が可能。

公式：Rundfunkbeitrag Antrag

生活アプリ・サービス

滞在中に使うアプリ・サービスの定番。

1. スーパー

Edeka / Lidl / Penny / Rewe / DM（ドラッグストア）。

2. 食

Too Good To Go：閉店前のパン屋・スーパーの福袋 €3–5。
Mensa（学食）：Studierendenwerk 運営。

3. 移動（近距離）

Donkey Republic：自転車シェア。UDE メールアドレスで登録すると毎日1時間無料。
Bolt / Uber：タクシー配車。

4. 移動（中〜長距離）

DB Navigator（電車）／ BahnCard 25/50（学割あり）／ FlixBus / FlixTrain（夜行安い）／ Omio（DB/Flix/Trenitalia 横断比較）。

5. 旅行

Skyscanner / Booking.com / Trip.com。ISIC（国際学生証）は日本で発行推奨。

6. 通信

WhatsApp：寮グループ・学内連絡はほぼこれ。
VPN：日本のサービス（Netflix / TVer 等）を見る時。

生活のヒント

現地に来て初めて気付く小さなこと。役所や大手アプリの手続きに載らない実用ネタ。

例：日曜は店が開いていない

スーパーも大半のカフェも日曜は閉店。土曜の買い出しがルーティンになる。（内容は後日加筆）

例：Pfand（デポジット）

ペットボトル・瓶を返却機に入れると €0.08–€0.25 が戻る。（内容は後日加筆）

例：現金 vs カード

退去（8〜9月）

帰国前に片付ける寮の退去と各種解約。デポジット返還には時間がかかる。

1. 寮退去

退去日の2ヶ月前までに Studierendenwerk へメールで連絡。
掃除 → 大家の事前検査→ 鍵返却 → デポジット返還（Mietende から約8週間、指定口座に自動返金）。

2. 引き継げるもの

WiFi ルーター・洗濯ラック等を、次の日本人 incoming へ引き渡し。

3. 各種解約

TK ／ Expatrio ／ ALDI TALK ／ 銀行口座 — 各サービスの解約手順を出発前に確認。
